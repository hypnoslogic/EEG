About this resource

Purpose

An open, referenced collection of teaching material on raw and processed EEG for anaesthetists at all levels, from registrars and medical officers to consultants. It is organised around the international Delphi learning outcomes{{cite:delphi2026}} and the structure of the Safe Brain Initiative boot camp{{cite:sbi2025}}. It is intended to be updated as new evidence appears.

Contributing and updating

The site is plain HTML generated from source fragments, so it can be hosted free on GitHub Pages and updated by anyone with access to the repository.

  1. Edit content in src/pages/*.html. Use the macros described at the top of build.py for citations, learning-outcome tags and figures.
  2. Add references to the end of src/references.json, giving a key, full citation, DOI and link, plus a licence note if relevant.
  3. Rebuild with python build.py. It stops with an error if a citation key or macro is wrong.
  4. Update the page's reviewed date and add a line to the changelog.
  5. Commit and push. GitHub Pages republishes automatically.

Suggestions, corrections and new evidence are welcome through the repository's issue tracker. Contributions from teachers, researchers, engineers and neuroscientists fit the Delphi advanced outcomes on mentorship, collaboration and spreading EEG knowledge ({{lo:MT2}} {{lo:LL2}} {{lo:LL6}}).
